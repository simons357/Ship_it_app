# The centered equation

\[
\Lambda'
=
-\frac{2\nu}{X}D_s
+\frac{2}{X}T_c.
\tag{3}
\]

That is the centered equation. Exact. Not an estimate.

Equivalent writings of the same identity:

\[
\Lambda'
=
\frac{2}{X}(T_c-\nu D_s),
\qquad
(\log\Lambda)'
=
\frac{2}{Y}(T_c-\nu D_s).
\]

Derivation: \(\Lambda=Y/X\), \(X'=-2\nu Y+2N\), \(Y'=-2\nu Z+2M\),

\[
\Lambda'
=
\frac{Y'X-YX'}{X^2}
=
\frac{(-2\nu Z+2M)X-Y(-2\nu Y+2N)}{X^2}
=
-\frac{2\nu}{X}\Big(Z-\frac{Y^2}{X}\Big)
+\frac{2}{X}\Big(M-\frac{Y}{X}N\Big),
\]

and \(D_s=Z-Y^2/X\), \(T_c=M-\Lambda N\), \(\Lambda=Y/X\).

This is not (4). Inserting \(T_c\le C\sqrt{D_s EY}\) is a different sentence.
This is not Young. This is not Need★.
