# Ship_it_app
It allows the user to manage what they put on Github easier without having to go on the Github site.

## Personal Cursor Setup Advisor

This repo includes a personal Cursor agent that helps you choose and configure the right Cursor features (Rules, Skills, Subagents, Cloud Agents, Automations, MCP, Plugins, Bugbot).

- Guide: [docs/CURSOR-SETUP-ADVISOR.md](docs/CURSOR-SETUP-ADVISOR.md)
- Install for all projects: `bash scripts/install-cursor-setup-advisor.sh`
- In Agent chat: ask for `cursor-setup-advisor`, or run `/cursor-setup-check`
