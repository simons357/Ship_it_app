# ChatVault repo inbox

This directory is how **any source** (AI chats, sounds, video, pictures,
papers, letters, DA audits) gets **into the git repo** — not only into
browser `localStorage`.

ChatVault’s tagline is **OS for your AI**. This is not a note-taking brand.

## What git holds

| Path | Role |
| --- | --- |
| `chatvault/inbox/*.json` | ChatVault export sidecars (`format: chatvault-export`). **Commit these.** |
| `chatvault/inbox/index.json` | Manifest of sidecar filenames. Regenerated by CLI ingest. |
| `chatvault/inbox/media/` | Binary copies (wav, mp4, pdf, …). **Usually gitignored.** |

JSON sidecars are the vault records: origin, source type, title, summary,
hashes, relative media path. Large media stays on local disk (or a future
LFS remote). Never commit secrets, credentials, or private clinical files.

## CLI (the copy-into-repo path)

```bash
python3 -m domain_architect --ingest-chatvault PATH
python3 -m domain_architect --ingest-chatvault PATH --inbox /tmp/vault-inbox
```

`PATH` may be a file or a directory. Text / markdown / JSON / ChatGPT
`conversations.json` / DA audits become full `ChatVaultEntry` rows with
`raw_content`. Pictures may embed a tiny data URL; otherwise the sidecar
points at `media/`. Audio, video, and PDF become **searchable stubs**
plus a media copy when the file is under the copy cap (100 MB). Above
that cap the JSON is still written; the binary is not copied.

Directory walks skip `node_modules`, `.git`, `__pycache__`, `.venv`.

A movie or sound is a human record, not a theorem. CLAIM_LEDGER stays
UNREVIEWED. Domain Architect does not prove Navier–Stokes or Riemann.

## Merge into the PWA

With `python3 -m domain_architect --site` (http://127.0.0.1:8765/):

1. **Load inbox from repo** in ChatVault ingest (or the DA dock) fetches
   `/chatvault/inbox/index.json` and imports the sidecars into
   `localStorage`.
2. **Send to repo** POSTs a JSON entry to `/api/inbox` on loopback only.
   That writes a sidecar. It does **not** upload 100 MB videos.

Standalone `python3 -m http.server` in `chatvault/` can still fetch
`./inbox/index.json` if those files exist; POST `/api/inbox` needs `--site`.

## Honest limits

- Browser vault is still `localStorage` (often 5–10 MB). Do not explode it
  with binaries. Use the CLI for media copies.
- No transcription of audio or OCR of PDF in this version.
- Gitignore covers `*.mp4` `*.mov` `*.wav` `*.mp3` `*.pdf` under `media/`.
  Tiny test bytes belong in a temp directory, not this tree.
