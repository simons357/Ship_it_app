# LISTENER iOS

SwiftUI shell for the first native milestone.

Open `Listener.xcodeproj` on a Mac. Bundle ID `tech.primefield.listener`.

Implements:

1. SwiftUI shell matching the prototype language
2. Persistent SwiftData `Session`
3. LISTEN HERE / GO SCOUT
4. Core Location breadcrumb, Start marker, RETURN polyline
5. MapKit FIELD / SAT / HYBRID
6. AVFoundation recorder, visible active input, originals in Documents/Originals
7. Field Notes with photo/video pickers
8. Replaceable `SyncTransport` + offline `SyncEvent` queue
9. Human-speech exclusion before library upload
10. Signal Library and Broadcast screens as real contracts — no fake species or COH
