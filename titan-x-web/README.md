# TITAN-X web (Vercel)

Static site for the **final investor plan**.

## Local

Open `index.html` or:

```bash
npx serve titan-x-web
```

## Deploy to Vercel

From repo root:

```bash
npx vercel --prod --yes titan-x-web
```

Or in the Vercel dashboard: **Add New Project** → import `Ship_it_app` → set **Root Directory** to `titan-x-web` → Deploy.
