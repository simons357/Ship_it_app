# Simons Anesthesia — projects & papers

**Owner:** Jonathan Simons, CRNA  
**Purpose:** One home for anesthesia teaching, papers, Vigilant Patch, and CV.  
**Status:** Folder scaffold ready. Drop files into the right slots.  
**Later:** Move this whole folder to its own private GitHub repo named `Simons-Anesthesia`.

---

## Open this folder when you’re on anesthesia work

In Cursor: work under `docs/anesthesia/` (or Open Folder on the future `Simons-Anesthesia` repo).

---

## Where to put things

| Folder | Put here |
| --- | --- |
| `cv/` | Current CV (PDF/DOCX). Old versions → `cv/archive/` |
| `papers/drafts/` | Active manuscripts (one subfolder per paper) |
| `papers/published/` | Final PDFs + a short `citation.txt` |
| `papers/reviews/` | Peer-review replies (keep private) |
| `teaching/` | Syllabi, slides, handouts |
| `projects/vigilant-patch/` | Vigilant Patch specs, drafts, sendable PDFs |
| `outreach/` | **PDFs you email** (talks, one-pagers, teaching CV) |
| `admin/` | Grants / IRB notes (sensitive — private repo) |

---

## First moves (30 minutes)

1. Drop your current CV into `cv/`.  
2. Drop any paper drafts into `papers/drafts/paper-name/`.  
3. For Vigilant Patch: put notes in `projects/vigilant-patch/docs/`.  
4. Anything you’d attach to an email → `outreach/` as PDF.  
5. Tell Cursor Agent: *“Help me outline my next anesthesia paper in papers/drafts/…”*

---

## Promote to its own GitHub repo (when ready)

1. GitHub → **New repository** → name: `Simons-Anesthesia` → **Private**.  
2. Clone it to your computer.  
3. Copy everything inside `docs/anesthesia/` into that new repo.  
4. Cursor → **File → Open Folder** → `Simons-Anesthesia`.  
5. From then on: anesthesia work only happens there.

Until then, this folder is your orderly home inside Ship_it_app.
