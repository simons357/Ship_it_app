# Wind the Standard Model backwards

`python3 scripts/da_machine.py lineage`

The poster did not arrive in one piece. It is prior theories
stacked, then expanded in components. DA connects those dots
**forwards** (assembly) and **backwards** (named limits).

This is not \(F\). Recovering Maxwell from \(\mathcal{L}_{\mathrm{SM}}\)
does not output \(g_s\). Tracks A, B, Q untouched.

---

## Forwards (how it was built)

Maxwell (1864) → Dirac (1928) → QED (1948).  
Fermi (1933) sits beside that as a weak contact term.  
Yang–Mills (1954) copies the gauge idea to a nonabelian group.  
Glashow–Weinberg–Salam + Higgs (1960s) = electroweak.  
QCD (1973) = color. Kobayashi–Maskawa = three families.  
't Hooft–Veltman: the broken theory is renormalizable.  
Higgs found 2012. That is the poster.

Einstein (1915) is **not** a layer of the poster. You add
\(S_{\mathrm{EH}}+\Lambda\) to get \(G_{\mu\nu}+\Lambda g=8\pi G\,T_{\mathrm{SM}}\).

## Backwards (the same dots, other way)

| Recover | Limit from \(\mathcal{L}_{\mathrm{SM}}\) | Verdict |
|---|---|---|
| Maxwell | QED, then \(\hbar\to 0\), keep the photon | **pass** |
| Dirac | one charged fermion, only \(U(1)_{\mathrm{EM}}\), \(m=yv\) | **pass** |
| Fermi | \(E\ll M_W\), integrate out \(W\); \(G_F=g^2/(4\sqrt{2}M_W^2)\) | **pass** |
| QED | SSB, \(e=g\sin\theta_W\), keep \(A_\mu\), drop \(W,Z,g,H\) | **pass** |
| Yang–Mills | drop matter and the VEV, keep one factor | **pass** |
| GWS | turn off \(g_s\) | **pass** |
| QCD | turn off \(g,g'\) | **pass** |
| one-group GUT | run the three couplings to the UV until they meet | **fail** (gauge3) |
| Einstein \(+T\) | derive \(G,\Lambda\) from \(\mathcal{L}_{\mathrm{SM}}\) | **fail** (must add) |
| Navier–Stokes | gluon cubic / continuum | **fail** (glue) |

Four limits run **both ways**: QED, Fermi, Maxwell, YM sit
inside the SM, and the SM is their assembly. That is what
“backwards as well as forwards” means here.

It does **not** mean the couplings run backwards to a meet,
or that history writes \(F\).
