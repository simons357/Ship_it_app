## The point

Anti-drone capability is the requirement. TITAN-X is a **modular ~20,000 lb** free-flight stratospheric aerostat — the hull / station-keeping platform. **What goes in the bay can be outsourced and integrated** (Raptor-class interceptor/effector, laser effector, or both as alternate modules). Prime Field does not need to invent every effector in-house to offer the persistent high-altitude host.

---

## Modular payload options (pick / mix / swap)

| Option | Framing | Integration note |
| --- | --- | --- |
| **A — Raptor-class interceptor / effector** | Kinetic or interceptor-style counter-UAS payload hosted from the gondola / underbelly bay | Lead with **outsource integrators** for the effector; TITAN-X supplies persistent loft, power budget planning, and modular interfaces |
| **B — Laser / directed-energy effector** | “Drop-in” or bay-mounted laser effector for soft/hard kill against small UAS (planning concept) | Same modular bay idea — power, cooling, cueing, and airspace deconfliction are integration topics, not claimed finished design |
| **A + B (alternate modules)** | Same hull; swap modules by theater or threat | Prefer this language when the buyer wants flexibility without locking one effector today |

**Do not say:** “we have a fielded Raptor + laser C-UAS aerostat.”  
**Do say:** “persistent modular host; anti-drone is a payload lane; effector vendors welcome.”

---

## Why host it on TITAN-X (planning logic)

- **Persistence** — buoyancy + solar station-keeping vs. constant aircraft burn for the same stare / protect volume.
- **Altitude band** — aircraft–satellite gap; useful for wide-area cueing and coverage concepts (planning range in the parent PDF).
- **Mass budget** — ~20,000 lb net supports substantial effector + sensor + power packages.
- **Civil dual-use of the same hull** — disaster / comms / observation modules when the anti-drone bay is not the active fit.
