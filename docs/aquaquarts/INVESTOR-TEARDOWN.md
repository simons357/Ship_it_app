# AquaQuartz — investor teardown (honest)

**Question:** If I were an investor, would I be interested?  
**Answer:** **Cautious yes — as a small hospitality / object brand seed, not as a water-tech unicorn.** Interest depends on locking COGS, the forever-vessel (anti-plastic) story, and proof at 1–2 venues. I would **not** fund carved-quartz fantasy chemistry or “most money to charity” before unit profit.

---

## 1. Would I write a check?

| I lean in if… | I walk if… |
| --- | --- |
| Guest is clearly buying **heirloom vessel + ritual + no plastic**, not “magic water” | Pitch leads with structured water / lithium medicine / MP science |
| Written maker quotes put kit COGS **≤ ~$100–110** at 100–200 units | Samples quote at **$150–220** with no path down |
| Trademark + LLC owns designs | Idea only, no IP fence |
| One restaurant (or hotel) LOI / paid pilot | Pure story deck, zero venue |
| Ask **$100–200k** for samples + inventory + pilots | Ask for millions with 50 countries day one |

**As an investor I’d offer:** small check or SAFE for Lithia + Savannah samples + 2 pilots — **after** seeing one written vessel quote and a draft trademark filing. Not a Series A. Expected return = lifestyle / niche brand optionality + Place Edition licenses, not SoftBank water.

**What I’d belive the buyer is paying for (rank order):**
1. Forever object (art on the shelf)  
2. **Avoiding single-use plastic** + conscience / date-night meaning  
3. Place pride (Lithia / Savannah / city)  
4. The water itself (must be decent; rarely the hero)

You’re right: **it’s not really the water.** The water must not suck. The spend is **vessel + ritual + plastic refusal + memory.**

## 2. Where the $70–$150 kit numbers come from

**They are not signed quotes.** They are **planning ranges** from:

| Source class | What we used |
| --- | --- |
| US / SE ceramic studio norms | Custom bottle/decanter samples often **$80–$250**/unit; drops toward **$40–$120** at ~50 |
| Hospitality stone/ceramic OEM (BAFA-class, India/Turkey hotel drinkware) | Marble/ceramic pieces often **tens of $** wholesale at volume — quote-driven |
| Anfora (Mexico) ceramic bottle OEM | Public: mold ~**$2,700+**, MOQ often ~**5,000** — scale path, not pilot |
| Asia stoneware OEM chatter | MOQ often **1,000–3,000**; unit cost falls hard vs studio |
| Glass studio accents | Purple insert/ring roughly **$8–$40** |
| Book + packaging + water | **~$10–35** combined in the model |

**Documented mid COGS for models: ~$110.** High end **$150–220** if you chase true carved stone.  
**Action before raise:** get **3 written quotes** (GA studio + 1 hospitality OEM + 1 glass). Until then, every $ number is a hypothesis.

## 3. Volume discounts — yes

| Volume | Typical pattern |
| --- | --- |
| 10–20 samples | Highest $/unit (studio) — **$100–250** body possible |
| 50–200 | First real brand run — target **$70–120** all-in kit if stoneware + glaze, not carved crystal |
| 1,000–5,000 | OEM molds; unit body can fall into **tens of dollars**; mold/tooling is the upfront check |
| Refill SKU | Almost no vessel cost — **this is where margin lives** |

**Investor rule:** Pilot proves desire at expensive COGS. Scale only if quotes show a path under ~$90–100 landed kit — or guest price rises to **$350–400**.

## 4. Unit math (clear)

Guest **$280** → restaurant **~$126** (45%) → brand **~$154**.

| Kit COGS | Contribution before OpEx / give-back |
| --- | --- |
| $70 | ~$84 |
| $110 | ~$44 |
| $150 | ~$4 ≈ break-even on the unit |

At $150 you are **buying a customer and a photo**, not a profit. That’s OK for pilot nights if COGS will fall — fatal if $150 is permanent.

## 5. Other venues (not only restaurants)

Anywhere people pay for **ceremony + object + conscience**:

| Venue | Why it fits |
| --- | --- |
| **Fine dining / chef’s table** | Core pilot |
| **Boutique hotels / turndown** | Place edition in room; take-home amenity |
| **Spa / wellness resorts** | Ritual water without medical claims |
| **Wedding / rehearsal venues** | Couple keeps the vessel — memory product |
| **Private clubs / yacht clubs** | Status object + no plastic story |
| **Museum / gallery cafés** | Art-forward; your designer story |
| **Corporate gifts / board dinners** | City pride editions (Savannah, Atlanta) |
| **DTC / site** | Full $280+ with no restaurant cut — best margin |
| **Wine shops / tasting rooms** | Adjacent to “terroir” buying |

Hotel + wedding + DTC often beat pure restaurant on margin (less 45% food-and-bev split).

---

## 6. Plastic / environment framing (investor-safe)

**Lead with:** forever vessel → **no single-use plastic bottle** from this experience → guest keeps art → published give-back to water causes.

**Do not claim:** “We solve ocean plastic” or “zero footprint” (stone/glass still have impact). Stay humble: **refuse the throwaway bottle + put money into stewardship.**

That story is stronger than “best water in the world” and matches what people actually buy at $280.

## 7. One-page investor verdict

| | |
| --- | --- |
| **Category** | Luxury hospitality object + place ritual (anti-plastic), not water tech |
| **Interest** | Soft yes at $100–200k if quotes + IP + 1 venue |
| **Risk** | COGS, restaurant cut, slow Place Edition sales |
| **Upside** | Refills, DTC, hotels/weddings, city licenses |
| **Must prove** | Written vessel quote ≤ ~$110 path; guest will pay; trademark filed |

**Bottom line:** I’d be interested in the **object that replaces plastic and commemorates a night/city** — not in the H₂O. Fix the kit cost, keep the plastic/heirloom story honest, expand venues past restaurants, and the math can become a real small brand. Leave it at $150 COGS forever and I’d pass.
