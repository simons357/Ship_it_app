## 3. Can you at least get a trademark?

**Yes — do this early.** Idea isn’t property; **AquaQuartz** (name + logo) can be.

### Practical path (US)

| Step | What | Ballpark |
| --- | --- | --- |
| 1 | Search USPTO TESS / hire search for “AquaQuartz” (and close spellings) in water, beverage, housewares, hotel services | Free–$500 |
| 2 | File **intent-to-use** or **use-in-commerce** application for word mark + later logo | USPTO fees often **~$250–$350+ per class**; attorney **~$1–2k** total common for a clean filing |
| 3 | Classes to discuss with attorney (examples): **032** (waters/beverages), **021** (glassware/decanters), maybe **035** or hotel-related if they advise | Don’t over-file classes you won’t use |
| 4 | Assign mark to **your LLC** | So investors buy into the company that owns it |
| 5 | Use ™ now on drafts; ® only after registration | |

*Not legal advice — use a Georgia IP attorney or a reputable filing service + attorney review.*

**Also protect:** copyright in booklet text and vessel drawings (automatic when you create them; optional registration); contracts with makers.

**Timeline:** Search this week → file within weeks if clear. Don’t wait for grocery.
