How to open on your machine

  1. In Cursor / the repo, go to docs/aquaquarts/
  2. Right-click index.html or complete-brochure.html → Open in Browser (or drag the file into Chrome)
  3. Print → Save as PDF to text or email

On GitHub: open the .html file → click “Raw” or download the folder, then open locally. GitHub does not always render HTML as a live page.
