# From idea → files → repo (plain English)

Cursor is **not** ChatGPT. ChatGPT = talk. Cursor = work inside **one project folder**. GitHub = that folder saved online with history (free).

---

## The three pieces

| Tool | What it is |
| --- | --- |
| Chat / Grok | Brainstorm |
| **Cursor** | Open a folder and edit real files |
| **GitHub repo** | That folder + versions (“commit” = save a snapshot) |

Always: **File → Open Folder** = the idea you’re working on today.

---

## Rule going forward

**One major idea = one GitHub repo.**

| Idea | Its own repo |
| --- | --- |
| AquaQuartz | Should eventually be `AquaQuartz` alone |
| Ship It app | `Ship_it_app` |
| Next idea | New repo named after it |

Don’t dump every idea into one mega-repo. That’s why AquaQuartz feels lost inside Ship_it_app.

---

## Folders inside each repo (keep it shallow)

```
MyIdea/
  README.md     ← 5 lines: what it is
  docs/         ← plans, notes
  renders/      ← pictures
  outreach/     ← PDFs you actually email
```

**Send:** files in `outreach/` (PDFs).  
**Keep internal:** long `.md` notes, drafts, strategy.

---

## New idea — steps today

1. GitHub → **New repository** → name it after the idea → Create  
2. **Clone** it to your computer  
3. Cursor → **File → Open Folder** → that folder  
4. Add `docs/`, `renders/`, `outreach/`  
5. Write a 5-line `README.md`  
6. Tell Cursor Agent: *“Make a simple folder structure for [idea].”*  
7. When something is sendable → put PDF in `outreach/` → commit → push
