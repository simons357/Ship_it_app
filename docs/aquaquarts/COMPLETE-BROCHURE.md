## 3. Do we even need to process?

**Often no — not the full train.**

If city water is already decent (Savannah usually is): **catalytic carbon + cold** removes chlorine / chloramine / mild sulfur. That is enough to show off the city.

| Path | When | Promise |
| --- | --- | --- |
| **A. Filter the place** | City pride (Savannah first) | Our water, cleaned of pipe taste |
| **B. House Sip** | Chase contest-level blinds | Crafted for taste (RO + remin) — label it |
| **C. True spring** | Lithia | Leave alone; serve cold |

**Never** RO Lithia and still call it Lithia Spring Water.

## 4. Tech & cost (each stage)

```
Place water → sediment → catalytic carbon
  → optional RO → optional remineralize
  → chill 4–10 °C → inert quartz vessel
```

| Stage | Does | Gear (approx.) | Ongoing |
| --- | --- | --- | --- |
| Sediment | Protect filters | $20–80 / in combo head | Replace on schedule |
| **Catalytic carbon** | Chlorine, chloramine, mild sulfur taste | **$350–500** commercial dual head (Everpure QT-class); residential ~$150–400 | ~$80–200 / change |
| RO | Flat blank | $400–1,500 under-counter; commercial $2k–7k+ | Membranes / prefilters |
| Remineralize | TDS ~200–350, pH ~7.2–7.8, Ca/Mg/HCO₃, low Na | $50–200 cartridge / kit | Packs / cartridges |
| Chill | Preference | $0–1.5k | Power / ice |
| Quartz vessel | Holds it — no chemistry | COGS goal ~$70–150 | Guest keeps |
| UV (optional) | Microbes only — **not** taste | $100–400 | Lamp yearly |

### Pilot buy

| Kit | Ballpark | Enough? |
| --- | --- | --- |
| **City pride (recommended)** — sediment + catalytic carbon + chill | **~$400–900** gear + $150–500 install | Usually yes for Savannah |
| **House Sip** — + RO + remineralize | **~$1.5k–6k** | When chasing “best in the world” |
| **Lithia** — source + cold (no RO) | Water deal + testing | Yes for heritage |

**High-leverage spend:** catalytic carbon alone (~$350–500 commercial).
