Architect, and not a published issue until Jon pastes them into an issue
file.

| File | For |
|---|---|
| [`jon-story.md`](jon-story.md) | A story Jon writes in his own voice |
| [`photos.md`](photos.md) | Photo captions and filenames |
| [`later-frequency.md`](later-frequency.md) | News items for a later Frequency |
| [`letters.md`](letters.md) | Notes from readers, if any |

Do not paste the 14 Sep shelf-book dump in as a live theory.
