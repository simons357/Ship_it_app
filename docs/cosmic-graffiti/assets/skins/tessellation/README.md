# Tessellation tray

Drop cool outputs from Jon’s tessellation app **here**.

This repo was searched for tessellation / tesselation / tessellate /
kaleido. The app is **not in this repo**. The tray starts empty on
purpose.

## How to wear a print

1. Put the picture in this folder (PNG is easiest).
2. Add a row to [`../skins.json`](../skins.json):
   - `kind`: `tessellation`
   - `files`: `tessellation/your-file.png`
   - `overlay`: that same PNG if the clip-on script should show it
3. Read [`../../../val8000-skins.md`](../../../val8000-skins.md).

These are clothes for the VAL8000 square. Pretty patterns. Not physics.
Do not revive NAV-42, Fluid-Q, or Q OS so a tiling looks like a theorem.
