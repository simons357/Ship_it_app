## Periodic box T³

![Teaching diagram: a transparent cube labeled Periodic box T³ filled with a lattice of cyan dots. A circled shell inside. Captions: opposite faces identified; fluid fills the cube — no hole in the center; wavevector space k in Z³; exact shell |k|² = α (one sphere). Footer: this is Fourier space bookkeeping, not cosmology.](assets/periodic-box-t3.jpg)

*Periodic box T³. Opposite faces identified. Fluid fills the cube — no hole in the center. The dots are wavevectors \(k \in \mathbb{Z}^3\). One circled sphere is an exact shell \(|k|^2 = \alpha\). This is Fourier space bookkeeping, not cosmology.*

A periodic box is a cube whose opposite faces are the same face. Walk off the right wall, you come in from the left. In that box a fluid can be written as a sum of waves, each tagged by an integer wavevector \(k\). The picture is that lattice of dots.

The fluid **fills** the cube. There is no magic cavity in the middle. The circle you see is not a hole in the room. It is one **shell** in wavevector space: every dot on that sphere has the same \(|k|^2\).

People sometimes look at a cube of dots and hear “universe.” The caption on the drawing already refuses that. Correspondence is not physical equivalence. A bookkeeping lattice is not a cosmology.

## Exact-shell interaction

![Teaching diagram: Exact-shell interaction. Points p and q on a large sphere (input shell |·|² = α) connect to an output wavevector k = p + q on a smaller shell |k|² = β. A vertical leftover length is labeled |k⊥|² = β(1 − β/4α). Note: when β → 4α the leftover vanishes. Caption on the leftover: this length is the shape of the claimed 4/3 bound.](assets/exact-shell-interaction.jpg)

*Exact-shell interaction. \(p\) and \(q\) live on the input shell \(|\cdot|^2 = \alpha\). Output \(k = p + q\) lands on shell \(|k|^2 = \beta\). The leftover length is \(|k_\perp|^2 = \beta(1 - \beta/4\alpha)\). When \(\beta \to 4\alpha\) that leftover vanishes. The picture names this length as the shape of a **claimed** 4/3 bound — a shape, not a close.*

Two waves on one shell can make a third. The drawing shows that as a triangle of arrows. What is left over, perpendicular to the output, is a length the picture writes down in closed form.

When the output shell gets as large as it can in this setup (\(\beta\) toward \(4\alpha\)), that leftover shrinks to nothing. That geometry is why people draw this diagram. It is **not** a certificate that unaugmented Navier–Stokes regularity is closed. **DA-VC-01** remains **FAIL**. The leftover in the classical problem stays **OPEN**.

Letters collide if you let them. The \(\Phi\) on a swirl poster, the \(\Phi\) Domain Architect prints, and a gravity \(\Phi_g\) will all answer if you shout the same sound. The box above is \(k\)-space. Different guest.
