## Type now, voice later

He **types** in the box. No audio. No Autoplay. No `val8000_speak.py` from
the UI. No espeak / Mac `say`. No stock ElevenLabs. Voice later, clone only.

Idle mouth is a straight line. After he types a reply, he smiles.
Unanswered questions: he types a help line, then smiles. He does not invent
theorems. He does not stamp TRANSFORMABLE without a real T. DA-VC-01 stays
FAIL.
