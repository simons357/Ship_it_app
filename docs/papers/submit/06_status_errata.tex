\section*{On Q6}

The inverse-GCD / ``Q6'' operator is a real matrix construction.
The prize narrative built on it --- that Q6 proves Goldbach, RH, or
Navier--Stokes, or that a full-spectrum Bridge floor holds --- does
\emph{not} stand.
The corrected public write-up is the note
\emph{The Inverse-GCD Operator \(Q_N\)}
(\texttt{04\_q6\_inverse\_gcd.tex}): definitions, Bridge$^*$
(single pair and multi-representation Goldbach vectors), nonnegative cone,
positive-GCD companion (\texttt{07\_positive\_gcd\_paper1\_abc.tex}),
and explicit withdrawal of false floors.
Route~C archived Lemma~A ($\mu\varphi/d^2$) and $R(v_{\mathrm{alt}})\to -1/(2\pi)$
are withdrawn; see \texttt{05\_route\_c\_conditional.tex}.
Use that note as a new version of
\texttt{10.5281/zenodo.20405589}.
