# Grok attack checklist — Domain Architect five-finger router

Adversarial prompts for rigor review. Prefer **failing inputs** and **invertibility counterexamples** over vibes.

## Mapping validity

- [ ] Does classical NS routing fire only on genuine NS forms, or on decorative symbol soup?
- [ ] Can two inequivalent PDEs receive identical five-finger inventories?
- [ ] Is Leray / div-free \(P\) earned from structure, or asserted by book membership?
- [ ] Gravity book: does \(P=I\) recover Newtonian Poisson as representation, or slogan-only?

## Hidden assumptions

- [ ] What does `E` silently assume (domain, Biot–Savart, zero-mode policy)?
- [ ] Are IC/BC treated as first-class or smuggled after the map?
- [ ] Does “auto-assign” hide confidence that should stay provisional (Level 0)?

## Dimensional / type holes

- [ ] Do role assignments carry units / tensor type, or only English labels?
- [ ] Can a free-index mismatch still “pass” reconstruct?
- [ ] Is \(\lambda\) subtype (viscosity vs \(R(\kappa)=1/\kappa^2\)) enforced at compare time?

## Noninvertible steps

- [ ] Reconstruct `passed=true`: inventory closure only — where is invertibility claimed too strongly?
- [ ] Drill-down recompose: can children cover parent labels while losing operator structure?
- [ ] Tuning export: can dialing a “free” control break a locked constraint without detection?

## Notation-only decompositions

- [ ] Product \(P\cdot H\cdot\psi\) treated as a single primitive anywhere?
- [ ] \(P\) read as prime / \(\mathbb{P}\) / packet mass without warning?
- [ ] \(\Phi\) overloaded with swirl or golden-ratio \(\varphi\) without alias?

## Overclaim / honesty gates

- [ ] Any path that suggests Clay / Millennium regularity?
- [ ] Any bake-in of \(\lambda_{\min}(Q_N)>-1/2\) into NS-B?
- [ ] Dual `--sfe-compare`: any hybrid synthesis or “winner” canonicalization?
- [ ] Incompleteness candidates: labeled book templates, or discovery language?

## Cross-book compare

- [ ] Shared role names (e.g. `scale_response`) implying physics transfer NS ↔ gravity?
- [ ] Unlike-book compare refusing false equivalence loudly enough?

## Process attacks

- [ ] Protocol freeze: can “discover” run before map/reconstruct honesty?
- [ ] Registry conflicts: can retired SFE ids be revived as canonical by CLI alone?

When filing findings: cite module path + minimal CLI reproduction.
