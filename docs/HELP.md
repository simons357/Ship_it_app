# Ship it — Help

Ship it is for the moment you’re done and need the thing to go somewhere — without spending another stretch figuring out how to send it.

Follow a short, standard path. Answer one question at a time. There’s always a Custom option. Add a semi-personal note. Ship it.

---

## The path

### 1. Ship it to?

Choose a standard destination (email, yourself later, cloud drive, a person, a team channel) **or** Custom — type exactly where it should go.

### 2. What do you want to happen?

Put the outcome in the box: send a file, share a link, deliver finished work, save for later, or Custom. Optionally attach a file or paste a link / detail.

### 3. Semi-personal note

Write a short human line. Check the summary. Tap **Ship it**.

### Boom

You’re done. It’s off your plate.

---

## Tips

- Prefer a clear Custom line over a vague preset if the preset isn’t quite right.
- Keep the note warm and short — one or two sentences.
- Don’t ship secrets into shared or public places.

## Status
