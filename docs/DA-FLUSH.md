# Hilbert flush of the 16

`python3 scripts/da_machine.py flush`

You asked whether quantum math can run the combinations and
flush which candidates are live. Yes, as **linear algebra**.
No, as a quantum device, and no as the shelved Quantum Lens.

There are 15 knobs. \(2^{15}=32768\) subsets. That is a
laptop, not Grover.

## The state

Put one basis vector on each candidate except \(R\) (output).
Amplitude is \(\sqrt{\max(\Delta\mathrm{lock}\,R,0)}\). Born
weight \(\lvert a_i\rvert^2\) is the fraction of score-mass
on that slot.

The flushed set (Born mass above the singleton cut) is the
same four as before: vacuum, Planck, \(S_c\), \(\delta\).
Best \(k=1\ldots 4\) combinations by Born mass grow that
same set. Category mass: gravity-gauge, then teleological,
then harmonic. Gauge and topological are near zero on this
score.

Grover’s \(\frac{\pi}{4}\sqrt{N/M}\) is written down only
as an illustration. You do not stand up a quantum machine
for fifteen knobs.

This is a rewrite of lock-\(R\). It does not produce \(F\).
If the Cosmo tags arrive, replace the amplitudes with those
tags or with a real residual from \(F\).

Waveform rules (superposition, entanglement, collapse,
falsification) are additive and live in
[`docs/DA-WAVE.md`](DA-WAVE.md). Unfalsifiable is not a pass.
