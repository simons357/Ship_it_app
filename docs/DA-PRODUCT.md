# DA product — what it is, what it can do, what it cannot

`python3 scripts/da_machine.py product`  
`python3 scripts/da_machine.py next --ask "what can I do with it if I license it"`  
`python3 scripts/da_machine.py next --ask "what's under the hood"`

This is a capabilities spec. It is not a contract
and not legal advice. Sell or license only what
sits here. Do not sell a leftover close.

---

## One sentence

DA is an **anti-bullshit process machine** for hard
leftovers. Ordinary AI proposes. Scripts score.
The operator runs the command. A sentence sits only
if it names a slot and a check that could kill it.

It is not a unifier. It is not a leftover solver.
Meta-success is a scored log, not a solved PDE.

## Under the hood

| Layer | What it is |
|---|---|
| Operator | names the problem; does not need the chops |
| Generator | ordinary AI (the agent). Phrases. Not a second author of an open WRITE |
| DA | Python commands in `scripts/da_machine.py` plus scored docs in `docs/` |
| Slots | A (\(Q_1\) PDE), B (classical NS), Q (inverse-GCD), U (process / score) |
| Checker \(V\) | maps a proposal to pass / fail / open |
| Log | `results/da_machine_log.json` — the experiment |
| Shelf | SFE, HB-as-unifier, prize packaging — archive, not a close |

Four live objects. Glue is refused: A is not B, Q is
not RH, Q is not BSD, U does not unify the forces.

Forbidden auto-fails include: “solved NS/RH,” full
\(Q\) floor, Biot–Savart depletion, BKM from \(L^2\),
SFE as a fluids or Hodge or \(\mathrm{P}\neq\mathrm{NP}\)
close, A⇒B.

B lemma catalog on this desk: pass 58, fail 192,
open 1 (`B_regularity`). Identities may pass.
Regularity has no pass.

Asking is the product. The operator does not need
to be a specialist.

## How to describe it if you license

**Allowed shape.** “A process machine: name a hard
leftover, get a ground-floor chain, diagnose the
break, refuse fake closes, score a candidate.”

**Not allowed shape.** “The system that solved the
leftovers.” “AI that finishes the last step.”
“Unifier.” “Prize package.”

The valuable datum is how far a non-specialist
operator can go when every claim is forced into a
slot and a fail-able check. That is “use AI to work
on problems,” not “AI said it is solved.”
