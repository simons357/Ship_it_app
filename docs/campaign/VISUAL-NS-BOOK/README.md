# Visual NS Book — one curriculum for Skool + Substack

**What this is:** a **visual-first education / map** of the Navier–Stokes regularity question and where this study stands relative to the spectral barycenter.

**What this is not:** a proof. Navier–Stokes / Clay Statement B is **not solved**. Lemma★ / DA-NS-1 is a **hypothesis**. Open doors stay open on the pictures.

Tone: host / guide. House-as-map is fine. No break-in metaphor, no platform shade, no trophy language.

| Platform | How to use this book |
