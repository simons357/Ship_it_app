### Day 4 — What “blowup” means
**Figure:** `docs/ns-review/assets/lemma-campaign/03-tug-of-war-stretch-vs-spread.png`  
**Skool [Desk]**

Blowup ≠ explosion ≠ Big Bang. In PDEs it means some size (usually spin/gradients) goes to infinity in **finite time**, so the smooth solution can’t continue.

If stretch permanently beats spread at the barycenter, \(\Lambda\) can run away — that’s the danger the door is about. Spectral-shift bookkeeping tracks the center; it is **not** the ★ bound.
