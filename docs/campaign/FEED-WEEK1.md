### Day 4 — What “blowup” means
**Figure:** `03-tug-of-war-stretch-vs-spread.png`  
**Skool [Desk robot]**

Blowup ≠ explosion ≠ Big Bang. In PDEs it means some size (usually spin/gradients) goes to infinity in **finite time**, so the smooth solution can’t continue. Theoretical singularity of the equations.

If stretch permanently beats spread at the barycenter, \(\Lambda\) can run away — that’s the danger the door is about.
