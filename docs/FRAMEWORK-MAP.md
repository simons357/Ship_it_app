## How a framework is scored

1. Name the leftover first.
2. Strike the specialty vocabulary
   (fitness, species, infection,
   metabolism, niche, genome).
3. Replace each word with an object
   that already sits on this desk.
4. Ask: does the replacement emit a
   printed ratio or an explicit
   integral of a named field?
5. If the replacement needs a
   discarded constitutive story
   (SFE, HB as unifier, \(K(t)\) in
   the PDE, 2-D \(\rho\) into 3-D,
   occupation from the wall detector),
   **STOP**.
6. Verdict is one of:

| Mark | Meaning |
|---|---|
| MAP | Rename or search process. Usable as language. Not a close. |
| RENAME | Already seated under another name. Do not rebuild. |
| STOP | Specialty leftover, or it restores a dead / withdrawn claim. |
| DEAD | No printed ratio and no hunt. Drop it. |

A MAP does not move a row off
[`ISSUES-SHEET.md`](ISSUES-SHEET.md).
