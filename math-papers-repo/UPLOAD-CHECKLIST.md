# Upload checklist — papers on GitHub

## Can I put all my papers on GitHub for exposure?

**Yes — if they are your preprints / your PDFs to share.**  
That’s normal. Zenodo + GitHub together is a good pattern:

- **Zenodo** = permanent DOI (cite this)  
- **GitHub** = easy discovery, README index, optional PDF copies  

## Do put

- Preprint PDFs you already put on Zenodo  
- This README index with DOI links  
- Short notes / errata (dated)  
- Optional small code that builds Q_N demos (later)

## Do not put (send check)

- Patent claim charts / enabling recipes meant for NDA  
- Defense dossiers marked vault  
- Secrets, keys, private correspondence  
- Someone else’s copyrighted PDF you don’t have rights to post  
- Over-claim language (“RH solved”) if the paper itself says conditional/open  

## Suggested GitHub repo name

`prime-field-math` or `simons-spectral-papers`

## Steps (plain language)

1. On GitHub: **New repository** → name it → Public → Create  
2. Upload this `math-papers-repo` folder as the contents (or ask twin to push once the empty repo exists)  
3. Drop PDFs into `papers/`  
4. Pin the repo on your GitHub profile  
5. Link it from the one-pager / primefield.tech when ready  

## I don’t have your updated math folder here

Twin only has titles + DOIs from the partner packet — **not** your latest local math drive.  
To finish: send the folder, Drive link, or drop PDFs into `papers/` and say **Rx: add these to the math repo**.
