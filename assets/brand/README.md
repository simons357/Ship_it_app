# Domain Architect mark

Canonical geometry lives in the SVG files. The PNGs are rendered
explorations of the same idea.

| File | Use |
|---|---|
| `domain-architect.svg` | Square app icon (graphite, silver, cyan bridge) |
| `domain-architect-wordmark.svg` | Icon + wordmark |
| `domain-architect-mono.svg` | Black / white stamp |
| `domain-architect-favicon.svg` | 32×32 micro-icon |
| `domain-architect-flat.svg` | Identity-sheet presentation on paper |

Reading, left to right:

1. vertical spine and three branches — decompose a system
2. cyan diamond — the only chromatic element; cross-domain translation
3. three branches closing to an apex — synthesize a candidate architecture

The mark may faintly imply D and A. It is not a letter monogram.

Do not add primes, harmonics, spirals, or field-equation motifs.
The cyan node is the translation interface, not a physical claim.
