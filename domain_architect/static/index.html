What is on the engine

ChatVault hybrid ranker chatvault-hybrid-0.2.0. Local, offline, no LLM ranker.

  1. Boolean match gate (AND / OR / phrases / field:)
  2. BM25F on words, stems, one-edit typos (K1=1.2)
  3. Character 3-gram BM25
  4. Field-weighted TF-IDF cosine
  5. Reciprocal Rank Fusion, k=60
  6. Optional RM3 expansion, fused again

Indexed fields: title, claim, theorem, gap, question, action, tag, book, summary, content, ai, source, origin. Ledger status and Harmonic Watch notes are never scores. AI conversations vs real papers/pictures/movies use origin:ai / origin:human.
