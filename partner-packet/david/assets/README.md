# Drop pictures & papers here

Put David-facing images and PDFs in this folder, then attach them after the three HTML one-pagers.

Suggested names:

- `portrait.*` — optional headshot (only if you want it)
- `product-*.png` — Operator Assist / Wave visuals
- `paper-*.pdf` — selected papers (A-grade only; no Clay unifiers)

The HTML sheets do not auto-embed these yet — Print the three pages, then append these files in your PDF merge.
