# Unreal 5 — later studio, same storyboard

This folder is **import notes**, not a fake `.uproject` that will not compile
without a 20 GB editor.

1. Copy `../storyboard.json` into the Unreal project as a JSON / DataTable.
2. Make a `UStruct` per chapter (`id`, `beat`, `title`, `set`, `action`, `lesson`).
3. Make a `UStruct` per dojo skill (`id`, `kind`, `seconds`, `motion`, `maps_to_pen`, `coach`).
4. Cel material: unlit, two-tone, speed-line post. Do **not** start with MetaHumans. That is waste for a Speed Racer cartoon.
5. Input: the Pen language — Twist / Click / Squeeze — plus a pose socket if you add Live Link or phone camera later.

Playable today is `../../dojo.html`. Budget engine is Godot in `../godot/`. Unreal is when there is a real animation budget.

Apple, F-35, and Godot/Unreal marks stay with their owners. This is not an official Japan Air Self-Defense Force sim.
